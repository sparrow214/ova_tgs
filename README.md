# OVA — Enfoques para el estudio de la Teoría General de Sistemas

Objeto Virtual de Aprendizaje (OVA) interactivo sobre el **Tema 11: Enfoques para el estudio de la TGS**. Es una página web que explica, con ejemplos, juegos y evaluación, la diferencia entre el **enfoque reduccionista** y el **enfoque sistémico**.

## 🔗 Página publicada

**https://sparrow214.github.io/ova_tgs/**

## 📚 ¿De qué trata?

El recorrido es **interactivo y guiado**: cada módulo se desbloquea solo cuando el estudiante resuelve el reto del anterior. Así se asegura la lectura y comprensión antes de avanzar.

Contenido:

1. **Portada** — presentación del tema.
2. **Enfoque reduccionista** — dividir el todo en partes (Descartes, Newton).
3. **Enfoque sistémico** — el todo organizado y sus relaciones (Bertalanffy).
4. **Análisis vs. síntesis** — el aporte de Russell Ackoff.
5. **Ejemplos** — el mismo caso visto con los dos enfoques (salud, empresa, software).
6. **Juego 1: Clasificador rápido** — clasificar frases por enfoque.
7. **Juego 2: Memoria de conceptos** — emparejar concepto y significado.
8. **Videos** — material audiovisual de apoyo.
9. **Quiz** — 5 preguntas con **puntaje automático**.
10. **Créditos y referencias**.
